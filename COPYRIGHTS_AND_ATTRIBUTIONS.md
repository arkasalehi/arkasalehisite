## Supabase visual language

The public site and workspace chrome follow the visual language of [Supabase](https://supabase.com) and [Supabase Studio](https://github.com/supabase/supabase) (`apps/studio` and `packages/ui`).

- Those packages are Apache License 2.0. Copyright belongs to Supabase and its contributors.
- This repository does **not** vendor Supabase source, the Supabase logo, the Supabase wordmark, or other trademarked assets.
- Colors, spacing, type pairing (a grotesk beside a monospace), and interaction timing are reimplemented here for Arka Salehi’s own brand. The green accent `#3ecf8e`, neutral dark scale, and `cubic-bezier(0.22, 1, 0.36, 1)` at about 200ms are the tokens this UI aligns with.
- Headings use [Manrope](https://fonts.google.com/specimen/Manrope) (Latin) with [Vazirmatn](https://fonts.google.com/specimen/Vazirmatn) for Persian. Mono uses [Source Code Pro](https://fonts.google.com/specimen/Source+Code+Pro).
